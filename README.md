# Miora — app downloads 🌸

**Miora** is a private period & wellness tracker with a cute companion, free on-device AI (English, Hindi, Hinglish), doctor reports and Health Connect sync. Your health data stays on your phone.

## Download

Go to **[Releases](../../releases/latest)** and download the newest `Miora-x.y.z-github.apk`.

**Installing on Android (8.0 or newer):**
1. Open the downloaded APK.
2. If Android asks, allow your browser or file manager to **install unknown apps**.
3. Tap **Install**.

**Updating:** Miora checks this page by itself about once a day. You can also check any time in **Profile → Check for updates**. Updates install over the old version, and your data stays.

> Got Miora from **Google Play**? Keep updating it from Play. Play and GitHub copies are signed differently, so one can't update the other.

## Privacy

- Miora has no account system and no server that stores your data.
- Checking for updates only asks GitHub whether a newer version exists. Nothing about you is sent.
